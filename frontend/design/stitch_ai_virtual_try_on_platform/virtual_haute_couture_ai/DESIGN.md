## Brand & Style

This design system drives an AI Virtual Try-On platform at the intersection of haute couture editorial elegance and cutting-edge computer vision. It blends high-end fashion aesthetics with fluid digital interactions, targeting modern fashion enthusiasts, digital stylists, and luxury e-commerce shoppers who expect flawless garment draping and personalized style synthesis.

The design movement is **Neo-Editorial Tech**: an expressive fusion of runway typography, generous ambient lighting, soft spatial curves (20px base radius), and deep cosmic blue tones. The interface emphasizes confidence, precision, and tactile immersion through silky smooth lighting, high-contrast imagery, and effortless interactive states.

## Colors

The chromatic structure balances profound depth with radiant electric illumination:
- **Primary (`#03035e` / `rgb(3, 3, 94)`)**: Deep cosmic navy anchoring primary call-to-actions, primary navigation elements, and editorial framing.
- **Secondary (`#e2ebfd` / `rgb(226, 235, 253)`)**: Ultra-soft crystalline blue acting as gentle backdrop fills for chips, accessory tabs, and secondary surfaces.
- **Tertiary / Accent (`#0248d4` / `rgb(2, 72, 212)`)**: Vibrant electric cobalt reserved for high-impact AI state signals, processing rings, generation badges, and active state indicators.
- **Neutral (`#0a050d` / `rgb(10, 5, 13)`)**: Inky near-black ensuring maximum typographic crispness against canvas backgrounds.

In dark mode, the palette transitions smoothly into a deep digital atelier with background `#020409` and elevated card surfaces at `#060a13`, accented by luminescent cobalt blues.

## Typography

**Bricolage Grotesque** serves as the unified voice across display, editorial headlines, UI controls, and body copy. Its distinctive geometric charm, tight aperture cuts, and variable personality communicate contemporary avant-garde fashion while retaining technical legibility.

All levels employ a subtle default negative letter-spacing (`-0.01em`), tightening to `-0.035em` for oversized display titles to create dense, impactful editorial statements. When paired with technical garment attributes, size metrics, or AI generation metadata, tabular layout numbers leverage monospace alignment.

## Layout & Spacing

The layout is built on a 12-column fluid grid system on desktop that scales down to 8 columns on tablet and 4 columns on mobile devices:
- **Desktop (>= 1280px)**: 12-column structure with `2rem` (32px) margins and `1.25rem` (20px) gutters. The layout reserves generous dual-pane viewport zones: an interactive avatar staging canvas on one side and a garment catalog/controls rack on the other.
- **Tablet (768px - 1279px)**: 8-column layout featuring collapsible dock controls and 1.5rem horizontal padding.
- **Mobile (< 768px)**: 4 columns with `1rem` (16px) margins and bottom-sheet interactive drawers allowing unobstructed garment previewing.

Spacing follows an organic 4px base increment (`0.25rem`), prioritizing breathing space around lookbook imagery and garment selection arrays.

## Elevation & Depth

Visual hierarchy leverages ambient, ultra-diffused atmospheric shadows that mimic studio spotlighting rather than harsh geometric drop shadows.

- **Level 0 (Flat Surfaces)**: Garment rack tracks, backdrop studio canvas (`#fdfcfe`).
- **Level 1 (Cards & Modules)**: `0px 4px 10px 0px hsl(0, 0, 0 / 0.10), 0px 1px 2px -1px hsl(0, 0, 0 / 0.10)`. Used on garment thumbnail tiles and option selectors.
- **Level 2 (Hover & Floating Panels)**: `0px 4px 10px 0px hsl(0, 0, 0 / 0.10), 0px 4px 6px -1px hsl(0, 0, 0 / 0.10)` combined with subtle 1px border (`#e6e1e9`).
- **Level 3 (Modals, AI Fitting Room, Flyout Drawers)**: `0px 4px 10px 0px hsl(0, 0, 0 / 0.10), 0px 8px 10px -1px hsl(0, 0, 0 / 0.10)`.
- **Level 4 (Prominent Preview Lightboxes)**: `0px 4px 10px 0px hsl(0, 0, 0 / 0.25)` providing depth for full-body virtual renders.

In dark mode, blur radiuses expand to 20px with elevated opacity (`0.50` to `1.25`) paired with faint cobalt luminous perimeter rings (`rgb(27, 26, 66)`).

## Shapes

The design system adopts an expressive **1.25rem (20px)** base radius across primary containers, interactive cards, and primary modules. 

- **Primary Cards & AI Canvas Viewports**: Rounded at `1.25rem` (`20px`), creating an organic lens shape that softens technical imagery.
- **Buttons, Inputs & Pill Tabs**: Derived proportionally—controls utilize `calc(1.25rem - 4px)` (16px) or fully rounded pill styles (`9999px`) for quick-selection garment tags.
- **Nested Elements (Internal Badges & Swatches)**: Nested radii follow the concave curve rule, scaled down to `calc(1.25rem - 6px)` (14px) or `8px` to preserve balanced concentric margins.

## Components

### Buttons
- **Primary CTA ("Try On Now", "Generate Look")**: Background `rgb(3, 3, 94)`, text `#ffffff`, border-radius `1.25rem`, height `48px`, padding `0 24px`. On hover, subtle elevation shift with accent glow tinting.
- **Secondary / Action**: Background `rgb(226, 235, 253)`, text `rgb(2, 72, 212)`, hover state transitions to `rgb(212, 226, 253)`.
- **AI Processing Button**: Displays animated electric blue gradient spinner (`rgb(2, 72, 212)`) with disabled pointer interactions and state labels ("Rendering Fit...").

### Cards (Garment & Model Viewports)
- **Garment Card**: Surface `rgb(255, 255, 255)`, border `1px solid rgb(230, 225, 233)`, radius `1.25rem`. Features an aspect-ratio container (`3:4` portrait), floating top-right bookmark chip, and bottom price/size metadata.
- **Try-On Preview Card**: Full-height canvas equipped with a floating dual-split slider handle to toggle original vs. AI-fitted outfits.

### Chips & Attribute Selectors
- **Size / Color / Fabric Tags**: Height `34px`, border-radius `9999px`, background `rgb(240, 238, 242)`, text `rgb(99, 93, 105)`. Active selected state switches to background `rgb(3, 3, 94)` with crisp white text.

### Input Fields & Upload Drops
- **Prompt & Search Inputs**: Height `48px`, border `1px solid rgb(230, 225, 233)`, background `rgb(255, 255, 255)`, border-radius `1.25rem`, inner padding `0 16px`. Focus state applies a `2px` ring in `rgb(61, 126, 255)`.
- **Photo Upload Dropzone**: Dashed border `2px solid rgb(2, 72, 212, 0.4)`, radius `1.25rem`, with smooth hover feedback tinting to `rgb(226, 235, 253, 0.5)`.

### Specialized AI Try-On Components
- **Pose / Angle Switcher**: Segmented pill control seated above the main avatar, letting users cycle 360° views.
- **Fit Accuracy Gauge**: Micro-badge with accent cobalt text indicating fit confidence percentage and drape accuracy.
